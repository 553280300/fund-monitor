# 基金监控

基金监控是一款基金、ETF 与指数信息监控工具。它按设定频率获取公开市场数据，在满足阈值时发送通知。

支持公募基金、ETF、A 股指数和常见海外指数。数据来源会显示在检查结果中，来源延迟、失败或停止服务时会明确提示。

支持两种部署方式：
- **Windows 本地应用**：双击 exe 打开管理面板（http://127.0.0.1:8420），本机定时监控、报告与通知。
- **GitHub Actions 云端**：把配置同步到仓库后，云端自动运行监控并推送报告到微信，电脑无需开机。

两种方式各自独立，也可配合使用（本地管理、云端盯盘）。

它只提供数据展示与提醒，不提供买卖指令、收益承诺或自动交易功能。
