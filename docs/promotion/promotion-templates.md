# Fund Monitor 推广素材

## 1. V2EX 发帖文案

标题：分享一个自己写的开源基金监控工具，大跌自动推微信

正文：

> 平时工作忙，没法一直盯盘，但又怕基金大跌没及时看到。之前试过几款监控软件，要么收费，要么推送不及时，要么功能太复杂用不上。
>
> 所以自己用 Python 写了个开源工具 —— **Fund Monitor**，核心功能就一句话：
>
> **把你想监控的基金/指数加进去，跌到阈值自动推送到微信。**
>
> 支持两种运行方式：
> - **Windows 本地端**：解压即用，适合想在本机跑的人
> - **GitHub Actions 云端**：配置好就自动跑，电脑不用开机，适合不想占本地资源的
>
> 推送渠道支持 PushPlus（微信）、Server酱、桌面通知、邮件、Telegram、Webhook。
>
> 功能亮点：
> - 实时行情（腾讯财经 + 东方财富双源）
> - 涨跌幅阈值告警 / 净值变动 / 分红 / 经理变更
> - 智能冷却（避免同一条消息反复推送）
> - 交易日定时监控（02:00/06:00/10:00/14:00）
> - 本地端 + 云端配置一键同步

## 4. 知乎回答模板

**问题方向**：「基金定投中，如何有效监控基金净值变化？」
**或**：「上班很忙，有什么好用的基金监控工具推荐？」

> 分享一个我自己的做法。我写了个开源项目叫 **Fund Monitor**，专门用来做基金和指数的自动监控。
>
> 核心思路很简单：
> 1. 把你关注的基金代码或名称加进去
> 2. 设置一个涨跌幅阈值（比如跌 1.5% 就提醒）
> 3. 到交易日自动跑，触发阈值就推送到微信
>
> 我用下来感觉最实用的几个点：
> - **不用一直刷 app**：跌了微信自动通知，涨了也通知
> - **冷却机制**：同一个基金 4 小时内不重复推送，不会被烦到
> - **双端可用**：Windows 本地跑也行，Fork 到 GitHub Actions 云端跑也行，电脑关机也能监控
>
> 项目地址：https://github.com/Frog755/fund-monitor
> 完全开源免费，欢迎 Star 和反馈。
