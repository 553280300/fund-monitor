# 通知渠道

支持**桌面通知、PushPlus（微信）、Server酱（微信）、邮件、Telegram 和通用 Webhook**。渠道名称、类型和非敏感参数保存在本地数据库；各渠道密钥（PushPlus Token、Server酱 SendKey、邮件授权码、Telegram Bot Token、Webhook secret）保存在 Windows 系统凭据库（keyring），不会写入数据库、日志或导出配置。

## 各渠道说明

| 渠道 | 用途 | 需要配置 |
|---|---|---|
| **PushPlus** | 微信推送（免费约 200 条/天，推荐） | Token（pushplus.plus 微信扫码注册获取） |
| **Server酱** | 微信推送（免费 5 条/天，备用） | SendKey（sct.ftqq.com 获取） |
| **桌面通知** | Windows 右下角弹窗 | 无 |
| **邮件（SMTP）** | 邮箱接收 | SMTP 主机、端口、用户名、发件地址、收件邮箱、密码/授权码 |
| **Telegram** | Telegram 消息（需能访问 Telegram） | Chat ID、Bot Token |
| **Webhook** | 任意 HTTP 端点（自建服务、企业微信/钉钉机器人等） | 完整 HTTP(S) URL，可选 secret |

## 配置步骤

1. 打开管理面板 → 「设置」标签页 → 添加推送通道
2. 选择类型 → 填写参数与密钥 → 保存
3. 点通道旁的「测试」按钮验证，收到消息即配置成功

## 触发时机

- **告警触发时**（涨跌幅/净值/分红/经理变更）：推送到规则指定的通道
- **每次监控完成后**：自动把完整监控报告推送到**所有启用通道**（微信/邮件/桌面等）

## 桌面通知说明

Windows 弹窗只显示**摘要**（前 180 字）；**点击通知**会打开管理面板并直接定位到「报告」页查看完整监控报告。

## 故障隔离

每个渠道的配置错误或发送失败只影响该渠道，不会停止监控或其他渠道投递；失败原因可在「测试」按钮处查看。
