# Windows 快速开始

1. 解压交付包（或从 GitHub Releases 下载 `FundMonitor-x.y.z-windows.zip`），双击 `FundMonitor.exe`。
2. 首次启动会在浏览器打开本地管理面板（http://127.0.0.1:8420），请等待最多 30 秒；若浏览器显示"拒绝连接"，等几秒后刷新即可。
3. **添加基金**（「监控」标签页右侧）：输入基金名称或 6 位代码（支持 `sh`/`sz`/`jj` 前缀，如 `sh000688`、`019860`）→ 搜索 → 选择匹配项 → 保存。类型和数据源自动识别。
4. **添加告警规则**：选择基金 → 规则类型（涨跌幅阈值/净值日变更/分红/经理变更）→ 阈值与冷却时间 → 保存。
5. **配置推送通道**（「设置」标签页）：推荐 PushPlus（微信）——注册 pushplus.plus 获取 Token → 添加通道 → 保存 → 点「测试」验证。
6. **执行监控**：点右上角「立即监控一次」手动运行；或等定时节点自动运行（默认交易日 02:00/06:00/10:00/14:00）。
7. 监控报告显示在「报告」标签页（每次监控自动保存，刷新不丢失），并推送到已配置的通道。

## 提示

- 应用默认只监听本机 `127.0.0.1`，无需安装 Python
- 运行数据保存到 `%LOCALAPPDATA%\FundMonitor`，密钥存 Windows 凭据库
- 数据仅供信息参考，不构成投资建议
